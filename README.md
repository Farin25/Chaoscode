# Chaoscode

## Project Overview

Chaoscode is a creative web project by Liam Selent and Farin Langner. This repository contains a collection of fun mini-games, interactive experiments, and visual web experiences built with HTML, CSS, and JavaScript.

The project aims to:
- provide playful, accessible browser projects for students, hobby coders, and web developers
- showcase a variety of ideas, from classic games to visual effects
- offer a fast introduction to web technologies without complex build tools

## Repository Contents

This repository includes several standalone web pages and projects, such as:

- `index.html` – main landing page with overview and navigation
- `snake.html` – classic Snake game in the browser
- `tetris.html` – early Tetris implementation
- `spaceshooter.html` – simple space shooter game
- `packman.html` – Pac-Man-inspired maze game
- `race.html` and `Quader -race.html` – racing game variants
- `math-quiz.html` – math quiz game
- `cookie-clicker.html` and `cookiev2.html` – clicker-style games
- `Random chaos generator.html` – random chaos generator project
- `Chaos particel explosion.html` – visual particle explosion effect
- `Pixel - Chaos Drawe.html` – pixel drawing application
- `lie_detector.html` – playful lie detector page
- `Namens_Generator.html` – random name generator
- `Lava_Leap.html`, `jumpandrun.html` and `Cps test.html` – additional game ideas and tests
- `about.html`, `impressum.html`, and `SECRET PAGE 🕵️.html` – info and supplemental pages

The repo also contains:
- `styles.css` – global styles and layout rules
- `images/` – supporting images for individual pages
- `LICENSE` – MIT license

## Project Structure

The structure is intentionally simple so the project can be opened directly in the browser:

- `*.html` – standalone modules and games as separate HTML files
- `styles.css` – central CSS file that can be used by multiple pages
- `images/` – static images and icons
- `Präsi/` – additional presentation material and resources

## Installation & Usage

No special development environment or extra software is required. To get started:

1. Clone or download the repository.
2. Open one of the HTML files in your browser.
3. The page will load immediately and can be used right away.

Alternatively, you can use a local web server to test relative paths more reliably:

- Windows: run `python -m http.server` in the project directory
- Then open `http://localhost:8000` in your browser

## Why This Project is Special

- ideal for experimenting with web technologies
- many different game ideas in one archive
